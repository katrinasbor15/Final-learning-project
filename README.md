# Выделение портретов заёмщиков банка

## О проекте

Итоговый проект профессиональной переподготовки по программе «Аналитик данных» Томского государственного университета.

Цель проекта — исследовать характеристики клиентов банка и выделить портреты заёмщиков в зависимости от категории платёжной дисциплины: BAD, MIDDLE и GOOD.

## Задачи исследования

- Загрузить данные и провести первичное знакомство с датасетом.
- Проверить данные на дубликаты, пропуски, аномальные значения и некорректные типы.
- Выполнить предобработку данных и подготовить признаки к анализу.
- Рассчитать возраст клиентов на основе даты рождения.
- Исследовать распределения числовых и категориальных признаков в разрезе платёжной дисциплины.
- Сформулировать и проверить статистические гипотезы.
- Составить аналитические портреты клиентов для каждой категории платёжной дисциплины.

## Инструменты

- Python
- pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Исследовательский анализ данных (EDA)
- Описательная статистика и проверка гипотез

## Этапы работы

### 1. Первичный анализ и предобработка

Проверены структура и качество исходных данных. Удалены дублирующиеся столбцы и записи, скорректированы названия и типы признаков, исследованы аномальные значения и обработаны пропуски.

### 2. Подготовка признаков

На основе даты рождения создан признак возраста клиента для дальнейшего исследования клиентских групп.

### 3. Исследовательский анализ данных

Изучены числовые и категориальные характеристики клиентов в разрезе категорий платёжной дисциплины. Рассмотрены возраст, активность переводов, суммы операций, лимиты и каналы привлечения.

### 4. Проверка гипотез

Сформулированы и проверены статистические гипотезы, связанные с различиями между группами клиентов. Результаты использованы для дополнения исследовательского анализа.

### 5. Формирование портретов клиентов

На основании выявленных закономерностей сформированы описания клиентов с категориями BAD, MIDDLE и GOOD.

## Основные выводы

- Клиенты категории GOOD в исследуемых данных совершали больше переводов, а средняя сумма перевода у них была выше, чем у двух других групп.
- Для клиентов с категорией GOOD наблюдались более высокие лимиты и большая активность операций.
- Среди более старших клиентов доля группы GOOD была выше, чем среди молодых.
- Выявленные различия использованы для формирования портретов клиентов по категориям платёжной дисциплины.

## Практическая значимость

Результаты исследования могут служить основой для дальнейшей сегментации клиентской базы, разработки маркетинговых кампаний и изучения факторов, связанных с кредитными рисками.

Выводы отражают закономерности в исследуемых данных и не доказывают причинно-следственную связь между характеристиками клиентов и их платёжной дисциплиной.
